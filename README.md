# Proton Drive versioning backup system
### Features
- backup via proton drive CLI
- login credential store via PASS
- incremental backups to allow for restore of previous backed-up files in case of corruption or other file issues/mistakes
- support for multiple local backup directories
- dedicated folder for each host running this

#### requirements
- PASS setup with gpg key
- offical proton drive CLI
